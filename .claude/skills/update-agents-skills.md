# 에이전트/스킬 업데이트 파이프라인

## 언제 업데이트하는가

| 트리거 | 업데이트 대상 |
|--------|-------------|
| 새 서비스 함수/모듈 추가됨 | 관련 agent 파일의 함수 목록 |
| OpenAI 프롬프트 수정됨 | `openai-integration.md` 프롬프트 규칙 |
| 새 Streamlit 컴포넌트 추가됨 | `streamlit-ui.md` 컴포넌트 목록 |
| 새 페이지 추가됨 | `CLAUDE.md` 페이지 목록 + `add-page.md` |
| 버그 수정 후 재발 방지 규칙 생김 | 해당 agent 파일의 주의사항 섹션 |
| 사용자가 선호/기피 방식 명시함 | 해당 agent 파일의 협업 규칙 섹션 |
| 반복되는 작업 패턴 발견됨 | `.claude/skills/` 에 새 스킬 파일 추가 |

## 업데이트 절차

```
1. 대화 중 업데이트 필요 시점 감지
   - 새 함수/파일이 생성됨
   - 기존 동작 방식이 변경됨
   - 사용자가 특정 접근 방식을 수정 또는 확인함

2. 해당 파일 수정 (Edit 툴 사용)
   .claude/agents/{domain}.md    ← 도메인별 전문 지식 업데이트
   .claude/skills/{workflow}.md  ← 워크플로우 절차 업데이트
   CLAUDE.md                     ← 전체 맵 반영 (필요 시)

3. 메모리 시스템에도 저장
   ~/.claude/projects/.../memory/ 에 feedback/project 타입으로 저장
   → 다음 세션에서 즉시 활용 가능
```

## 각 에이전트 파일 업데이트 포인트

### ppt-renderer.md
- 새 슬라이드 타입 추가 시: 함수 목록 + 주의사항
- 스타일 규칙 변경 시: "슬라이드 스타일 규칙" 섹션

### openai-integration.md
- 모델명 변경 시: 함수 설명의 모델 항목
- 프롬프트 규칙 변경 시: "프롬프트 규칙" 섹션
- 새 API 함수 추가 시: "API 함수 목록" 섹션

### lyrics-assistant.md
- 크롤링 소스 변경/추가 시: 크롤링 함수 목록
- 새 내보내기 포맷 추가 시: "내보내기 함수" 섹션
- 세션 키 추가/제거 시: "세션 키" 목록

### streamlit-ui.md
- 새 컴포넌트 추가 시: 컴포넌트 목록 테이블
- CSS 클래스 추가 시: "CSS 클래스 목록" 섹션
- 레이아웃 패턴 변경 시: "레이아웃 패턴" 섹션

## 새 에이전트 파일 추가 기준

새 도메인 기능이 생기면 `.claude/agents/{name}.md` 추가:
- 담당 파일 명시
- 핵심 함수/클래스 목록
- 주요 데이터 포맷
- 주의사항 (재발 방지 규칙)
- 협업 규칙 (Claude가 작업 시 따를 규칙)

## 새 스킬 파일 추가 기준

반복 작업 패턴이 2회 이상 등장하면 `.claude/skills/{name}.md` 추가:
- 트리거 조건 명시
- 단계별 절차
- 체크리스트 (해당 시)
- 예시 코드 (해당 시)
